# Aigocy Header + Hero — Astro Reference Project

## Run locally
1. Install Node.js 20.3+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:4321.

## Included
- Astro scaffold with separate Header and Hero components.
- All response bodies captured in the supplied HAR, mapped into `public/` using their original URL paths so relative CSS image/font references continue to resolve.
- Captured theme CSS, JS, images, SVGs, fonts and icon font.
- Original captured homepage HTML, HAR (if available) and manifest in `reference-source/`.

## Scope
Only the Aigocy header and hero are implemented. The tiny placeholder after the hero marks where the next homepage section will be added.
This is a frontend reference recreation, not a WordPress backup. PHP, server-side functions and unrequested resources are not included.
Confirm applicable theme and asset licensing before publishing or using the original assets commercially.
